# Build a Survey Form — Car Owner Survey

A car-themed version of the **Build a Survey Form** project from the **HTML section** of freeCodeCamp's **Responsive Web Design certification**.

## Features

- Fields for car make, model, year, and color
- Radio buttons, checkboxes, and a comments box
- Built-in HTML form validation and a simple JavaScript thank-you message
- Responsive layout for desktop and mobile

## Technologies

HTML, CSS, and JavaScript, all included in one `index.html` file.

## Run Locally

Open `index.html` in a web browser.

This is a front-end demo. Responses are not stored or sent.
