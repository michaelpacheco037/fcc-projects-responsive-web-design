# Build a Page of Playing Cards

A project from freeCodeCamp's **Responsive Web Design certification**, practicing **CSS Flexbox** to arrange and align playing cards.

## Features

- Three playing cards with ranks and suit symbols
- Centered, wrapping layout with a 20px gap
- Rounded corners, shadows, and a simple hover effect

## Technologies

HTML and CSS, both included in one `index.html` file.

## Run Locally

Open `index.html` in a web browser.
